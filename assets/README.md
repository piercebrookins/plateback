# Sample assets

The records are fictional, not measured UVA results. The 48 photos are illustrative served-food images from Nutrition5k, not observations of those returns.

Photo attribution: Thames et al., Nutrition5k: Towards Automatic Nutritional Understanding of Generic Food, CVPR 2021. Source: https://github.com/google-research-datasets/Nutrition5k. License: CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Prior preparation may include resizing. Source IDs are recorded in demo-dining.json.

benchmark.json preserves recorded evaluation results. The Models page displays a subset. The twelve-image pilot is not a general ranking or dining-hall deployment evaluation. Model configuration files identify the selected checkpoint and inference settings; weights are separate.
